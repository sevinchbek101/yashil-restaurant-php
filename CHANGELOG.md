# Changelog

## PHP Version 1

- Version 23 dizayni PHP 8 + vanilla JavaScript sahifalariga ko‘chirildi.
- Cloudflare D1 o‘rniga MySQL va PDO prepared statements qo‘shildi.
- Menyu, savat, checkout, kuzatuv va admin panel PHP API bilan ishlaydi.
- CHECKOUT.UZ invoice, return URL va webhook tekshiruvi ko‘chirildi.
- API kaliti AES-256-GCM bilan shifrlanadi.
- CSRF himoyasi, xavfsiz sessiya cookie’si va login rate-limit qo‘shildi.
- XAMPP/cPanel uchun installer, `.env.example`, Apache rewrite va qo‘llanma yaratildi.
